📊 개인화 AI 주식 리포트 자동화 시스템

상세 기획서 및 아키텍처 명세서 (v1.0)

1. 프로젝트 개요 (Project Overview)

  • 프로젝트명: 퀀트 & 센티멘트 기반 AI 주식 대시보드 (가칭: StockInsight AI)
  • 목적: 흩어져 있는 글로벌 거시 경제 지표, 개별 종목의 펀더멘털, 실시간 뉴스를 통합하고 LLM(대규모 언어 모델)을 통해 분석하여 매일 아침 직관적인 투자 인사이트를 제공한다.
  • 타겟 사용자: 1인 (개인 맞춤형 투자 결정 지원 툴)

2. 기술 스택 (Tech Stack)

🗄️ Backend & Infra

  • Framework: FastAPI (Python 비동기 처리)
  • Package Manager: Poetry (pyproject.toml 기반 엄격한 의존성 관리)
  • Database: PostgreSQL (asyncpg, Pydantic)
  • Task Queue: Celery + Redis (스케줄링)

💻 Frontend (UI/UX)

  • Framework: Next.js (App Router 활용)
  • Styling: Tailwind CSS, 점진적 공개(Progressive Disclosure) 패턴
  • Data Fetching: SWR 또는 React Query (Cache-aside)

🤖 AI & Data Pipeline

  • Data Sources: yfinance(해외), pykrx(국내), DART API(공시), FRED/News RSS
  • LLM API: Gemini API (또는 GPT-4o / Claude 3.5)

3. 핵심 기능 명세 (Core Features)

  1. AI 기반 센티멘트 분석 및 하이드 바 (Hide Bar): 크롤링된 실시간 뉴스를 LLM이 분석하여 0~100점의 스코어 도출. UI에서는 뱃지만 노출하고 클릭 시 원문/3줄 요약/흐름을 하이드 바로 제공.
  2. 등락률(%) 기반 AI 종목 추천 (Long/Short): 거래량/시총 상위 종목을 스캔하여 예상 등락률을 도출하고 내림차순 정렬 렌더링.
  3. 기업 펀더멘털 실시간 조회 (Cache-aside): PBR, PER, ROE, 시가총액, 배당수익률, 외국인 소진율 제공. DB 캐시 만료 시 외부 API로 즉각 갱신.
  4. LLM 기반 종목 강점(Strengths) 스코어링: 5가지 지표(수익성, 성장성, 저평가, 안정성, 모멘텀) 기반 레이더 차트 및 해시태그 생성.
  5. 디스코드(Discord) 모닝 알림 자동화: 매일 08:30 장 시작 전 관심 종목 이슈 및 Long/Short Top 3를 Embed 메시지로 발송.

4. 화면 및 라우팅 설계 (Information Architecture)

  • 🏠 /app/page.tsx (홈 오버뷰): 글로벌 매크로 지표 롤링 티커, AI 요약 브리핑.
  • 📌 /app/watchlist/page.tsx (내 관심 종목): 펀더멘털 지표 테이블, 종목별 강점 레이더 차트 및 해시태그.
  • 🚀 /app/discover/page.tsx (AI 예측 및 탐색): 전체 시장 스캔 기반 Long/Short 종목 리스트 (등락률 내림차순 정렬).
  • 📰 /app/news/page.tsx (뉴스 허브): 마켓 센티멘트 게이지, 핫 키워드 태그, AI 필터링 뉴스 타임라인.
  • ⚙️ /app/settings/page.tsx (환경 설정): 관심 종목 티커 관리, 디스코드 Webhook URL 설정.

  • Step 3: yfinance, pykrx 연동 및 LLM API 프롬프트 주입 테스트.
  • Step 4: 프론트엔드 연동을 위한 /api/stocks, /api/news REST API 구축.
